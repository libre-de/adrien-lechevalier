# Adrien Lechevalier

Site personnel en français : enseignement, direction marketing externalisée et agence web Solayia.

## Structure

- `index.html` : accueil et articulation des trois activités
- `enseignant.html` : intervention en école et formation
- `direction-marketing.html` : direction marketing et communication à temps partagé
- `agence-web.html` : offre web portée par Solayia
- `styles.css`, `script.js`, `favicon.svg` : design partagé, menu mobile et identité

## Prévisualisation

Depuis ce dossier :

```bash
python3 -m http.server 8000
```

Ouvrir `http://localhost:8000/`.

## Mise en ligne sur GitHub Pages

Le site est statique et ne nécessite ni compilation ni clés d'API. Publier la branche principale depuis la racine du dépôt dans **Settings → Pages → Deploy from a branch**. L'adresse sera `https://<compte>.github.io/<depot>/` si le dépôt ne porte pas le nom `<compte>.github.io`.

Les liens internes sont relatifs pour fonctionner avec un chemin de dépôt GitHub Pages. Les prises de contact ouvrent l'adresse professionnelle et l'agenda Solayia existants ; aucun formulaire ni traqueur n'est chargé. Les polices Google sont optionnelles : les polices système prennent le relais si elles ne chargent pas.

Avant de relier un domaine personnalisé, vérifier les mentions légales et décider du traitement des données de fréquentation si un outil de mesure est ajouté. Mettre à jour les affirmations chiffrées si les chiffres définitifs du CV changent.
